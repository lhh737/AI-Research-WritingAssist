## 开题报告

### 整体思路

解决办法：

逻辑： 我研究什么 -> 为什么研究？研究了有什么用，能解决、提升、改善改良什么？贡献？ -> 怎么研究的？-> 对框架的 论述、论证、实验、结果分析总结 

工科灵感： 

AI对话 -> "我的本科院校层次：XX，专业：XX，目前需要写毕业论文，但没有好的方向和项目，你有什么好的想法？结合当下主流稳健的技术方向，难度适中，符合本科生毕业标准"
       -> "（初步方向）"
       -> "，（完成技术选型、技术栈）"
       -> "（完整计划）"
       
资源 ： Github /Gitee /B站 /




本校的论文格式文档、参考一般在 学校官网 资源下载处 寻得

### 开题报告细纲生成

````markdown


本校格式参考：{XX}，论文大体思路：{XX}，根据我的参考材料生成一篇本科开题报告，只输出完整的大纲给我，其中包含子小节逻辑清晰、分论点明确的细纲，不需要正式的正文内容，要求：每一分节可以有简略介绍，大致介绍这部分会做什么，着重优化大纲的整体逻辑性与编排，符合本科生毕业论文要求

````
### 开题报告大纲调整
````markdown

````
